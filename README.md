# 📝 Task Manager

A simple full-stack Task Manager website built while learning web development.

## 🚀 Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite
- Git & GitHub

## ✨ Current Features

- Add tasks
- View saved tasks
- Complete tasks
- Delete tasks
- Tasks remain saved after refreshing the page
- SQLite database for storing tasks
